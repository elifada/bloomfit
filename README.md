# BloomFit AI — GitHub Pages website

BloomFit is a student PE project prototype. It creates a simple session outline from a student's selections.

## Files
- `index.html` — page structure
- `style.css` — pink and sage-green design
- `script.js` — plan-generation logic

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `bloomfit-ai`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's top level (not inside another folder).
3. Open the repository's **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait a few minutes. GitHub will show the public website address in the Pages section.

## Important project note
This prototype uses JavaScript rules; it does **not** call a real AI model. Describe it accurately in your school project as an AI-inspired or rule-based prototype unless you later connect an AI API. Do not put private API keys in browser-side JavaScript. Have a PE teacher review activities and adapt them for the class.
